# Análisis Estadístico de Ventas: BOSI y BAMBINO

## 1. Descripción del proyecto

Este proyecto tiene como objetivo analizar el comportamiento de las ventas de las marcas BOSI y BAMBINO durante las semanas 35 a 39 de 2026, mediante herramientas de análisis estadístico y visualización de datos.

El trabajo se desarrolla a partir de mi experiencia laboral en Comercializadora Baldini S. A., utilizando datos reales de ventas y presupuestos comerciales suministrados por la compañía. La información permite evaluar el cumplimiento de las metas, identificar variaciones semanales y comparar el comportamiento comercial de ambas marcas.

## 2. Objetivos

- Analizar estadísticamente las ventas semanales de BOSI y BAMBINO.
- Calcular medidas descriptivas e indicadores de cumplimiento de metas.
- Comparar el comportamiento de las ventas entre las dos marcas.
- Aplicar pruebas estadísticas para explorar diferencias y relaciones entre los datos.
- Generar gráficos que faciliten la interpretación de los resultados.

## 3. Datos utilizados

La base de datos contiene 10 registros correspondientes a dos marcas durante cinco semanas, desde la semana 35 hasta la semana 39 de 2026.

Las principales variables analizadas son:

- Semana: periodo de análisis.
- Marca: BOSI o BAMBINO.
- Meta: presupuesto de ventas establecido.
- Mínimo: presupuesto mínimo esperado.
- Real: valor de las ventas efectivamente registradas.
- Cumplimiento: porcentaje de cumplimiento de la meta comercial.

Los datos utilizados corresponden a registros reales de la actividad comercial de la compañía y no a datos simulados.

## 4. Herramientas y tecnologías

El proyecto se desarrolló en Python mediante Google Colab, utilizando las siguientes bibliotecas:

- **Pandas:** organización y procesamiento de los datos.
- **NumPy:** operaciones numéricas.
- **Matplotlib:** elaboración de gráficos.
- **SciPy:** aplicación de pruebas estadísticas y análisis de correlación.

## 5. Metodología

El análisis se desarrolló mediante las siguientes etapas:

1. Recolección y organización de los archivos de ventas y presupuestos.
2. Limpieza y validación de la información.
3. Cálculo de estadísticas descriptivas e indicadores de cumplimiento.
4. Elaboración de gráficos comparativos.
5. Aplicación de la prueba de Wilcoxon y la correlación de Spearman.
6. Interpretación de los resultados y formulación de conclusiones.

## 6. Resultados esperados

El análisis permite identificar las semanas con mayores y menores ventas, evaluar el cumplimiento de las metas comerciales y comparar los resultados de BOSI y BAMBINO. Asimismo, las pruebas estadísticas permiten explorar posibles diferencias y asociaciones entre los resultados semanales, teniendo en cuenta el tamaño reducido de la muestra.
